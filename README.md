# PDF 번역기

PDF 파일을 Google 번역으로 자동 번역하는 데스크톱 앱입니다.  
**API 키 불필요 · 무료 · 설치 없이 exe 파일 하나로 실행**

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| **이미지·도형 보존** | 그래프·플로우차트·배경 도형 유지, 텍스트만 교체 |
| **출판 품질 레이아웃** | 상단 여백 기준 리플로우, 1.75× 행간, 출판용 명조체 |
| **이미지 공간 자동 확보** | 그래프가 있는 페이지는 이미지 아래부터 텍스트 시작 |
| **표지·챕터 보호** | 텍스트가 적은 특수 페이지는 overflow 받지 않음 |
| **URL 줄바꿈** | 공백 없는 긴 URL도 bbox 폭에 맞게 문자 단위 분할 |
| **빠른 번역** | 블록 묶음 병렬 처리 (6개 동시 요청) |
| **드래그 앤 드롭** | PDF를 창에 끌어다 놓으면 바로 선택 |
| **진행률 표시** | 60fps easing 애니메이션, 타임스탬프 로그 |
| **설정 자동 저장** | 마지막 언어 설정 자동 기억 |

## 실행 방법

### 바로 실행 (권장)

```
dist/PDF-번역기.exe
```

별도 설치 없이 더블클릭으로 실행됩니다.

### 소스에서 실행

```bash
pip install -r requirements.txt
python gui_translator.py
```

---

## 사용법

1. **PDF 파일 선택** — 드래그 앤 드롭 또는 [클릭하여 선택]
2. **출력 경로 확인** — 자동 설정됨, 필요 시 변경
3. **언어 설정** — 소스 언어(자동 감지 가능), 타겟 언어 선택
4. **번역 시작** 클릭
5. 완료 후 PDF 파일이 지정 경로에 저장됨

---

## 번역 처리 흐름

```
PDF 입력
  ↓ [1/3] PyMuPDF  →  전체 텍스트 블록 추출
  ↓ [2/3] Google 번역  →  블록 묶음 병렬 번역 (6개 동시)
  ↓ [3/3] PyMuPDF  →  원문 제거 후 페이지 리플로우, PDF 저장
번역된 PDF 출력
```

---

## 출력 방식

- 원본 텍스트를 제거(`redact`)하고 페이지 상단 여백부터 순서대로 리플로우
- 배경 도형·이미지는 `PDF_REDACT_IMAGE_NONE` 플래그로 보존
- 이미지가 있는 페이지는 이미지 하단 이후부터 텍스트 배치
- 텍스트가 페이지를 넘으면 다음 페이지로 자동 이어짐 (페이지 수 증가 허용)
- 표지·챕터 오프너 등 특수 페이지는 자신의 콘텐츠만 받고 overflow 차단
- **폰트 우선순위**: KoPubBatangMedium → NanumMyeongjo → HANBatang → Batang → Malgun Gothic
- **행간**: 1.75× (한국어 출판 표준)
- **폰트 크기**: 블록 내 글자 수 기준 최빈값 사용 (각주 번호 등 소형 span 오염 방지)

## 요구 사항

## QA 자동화

`qa_agent.py` — 번역 품질을 자동으로 평가하고 리포트를 생성합니다.

```bash
python qa_agent.py          # 번역 + 평가 (100페이지)
python dev_loop.py          # QA 리포트 분석 → 점수 ≥ 60이면 자동 빌드
```

### QA 평가 항목

| 항목 | 감점 |
|---|---|
| 빈 페이지 (원문 있는데 번역 없음) | -20점/페이지 |
| 텍스트 겹침 | -15점/페이지 |
| 과소 폰트 (6pt 이하 30% 초과) | -10점/페이지 |
| 이미지 위 텍스트 겹침 | -10점/페이지 |
| 좌우 여백 부족 | -5점/페이지 |

---

## 주의 사항

- **스캔 PDF (이미지 PDF)** 는 텍스트 추출이 되지 않아 번역되지 않습니다
- 번역 텍스트가 원본보다 길면 다음 페이지로 이어집니다 (페이지 수 증가 가능)
- Google 번역 무료 사용으로 **일일 요청량이 많을 경우 일시적으로 제한**될 수 있습니다
