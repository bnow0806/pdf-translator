# PDF 번역기 — 개발 히스토리

Claude와의 대화로 만들어진 기능 목록 및 트러블슈팅 기록입니다.

---

## 1. 프로젝트 시작

**요청:** deepl 기반 pdf 번역 프로그램을 만들어줘

**구현:**
- `pdf_translator.py` — DeepL Document Translation API 기반 CLI 도구
- 기본 모드: 레이아웃 보존 (문서 API)
- 텍스트 모드: pdfplumber + fpdf2
- `requirements.txt` 작성

## 2. exe 파일로 패키징

**요청:** exe로 실행할 수 있게 해줘

**구현:**

## 4. API 키 안내 버그 수정

## 9. 포맷 보존 번역 (pdf2docx 파이프라인)

**요청:** 총 347 페이지인데, 문서 포맷 유지하면서 번역할 수 있는 거니? / 그림도 유지됐으면 좋겠어

**구현:**
- `pdf2docx` — PDF → DOCX 변환 (그림·표·텍스트 구조 보존)

- 출력: DOCX → PDF (`docx2pdf` + `win32com`)
- spec에 numpy / cv2 / pdf2docx / fitz `collect_all` 추가

## 10. 진행률 · 출력 형식 · 속도 · UI 개선

**요청:** 진행 상황은 퍼센트로 순차적으로 증가했으면 좋겠고, 출력본도 같은 PDF로 해줘. UI는 하얀 배경으로. 속도가 너무 느린데 빨리 됐으면 좋겠어

**구현:**
- 진행률: 불확정 스피너 → 0~100% 결정적 progressbar + 퍼센트 레이블
  - 1/3: PDF 변환 (시간 기반 애니메이션)
  - 2/3: 번역 (단락 단위 실시간)
  - 3/3: PDF 저장
- UI: 다크 → **라이트 테마** (흰 배경, Windows 스타일)
- 출력: DOCX → **PDF 직접 저장** (`docx2pdf`)
- 속도: `translate_batch()` 루프 → **단락 묶음(SEP 구분) 1회 요청** + **6개 병렬** (30~50배 향상)

## 11. Converter.pdf_file 오류 수정

**요청:** 오류: 'Converter' object has no attribute 'pdf_file'

**원인:** pdf2docx 최신 버전에서 `pdf_file` 내부 속성 제거됨

**수정:**
- `fitz.open()` 으로 페이지 수 파악
- 변환 중 진행률은 경과 시간 기반 애니메이션으로 대체

## 12. 번역 속도 추가 최적화

**요청:** 번역하는데 왜 이렇게 오래 걸려? 병렬 프로그래밍 할 수 있어?

**원인:** `translate_batch()`가 내부적으로 단락마다 HTTP 요청을 개별 발송

**구현 (`_translate_joined`):**
- 단락들을 `◆◆◆` 구분자로 이어 붙여 **1번 API 호출**로 묶음 번역
- 구분자 불일치 시 절반씩 재귀 분할 재시도
- `ThreadPoolExecutor(max_workers=6)` 병렬 처리

## 13. PDF 출력 요청

**요청:** 출력 파일이 DOCX가 아니라 PDF로 해줘

**원인:** `docx2pdf`가 exe 내에서 실패 시 DOCX 폴백이 동작했음

**구현 (`_docx_to_pdf`):**

- `DisplayAlerts = 0` — 모든 팝업 억제
- `AutomationSecurity = 3` — 매크로 비활성화
- LibreOffice 폴백
- 최종 DOCX 폴백

## 14. Word 변환 시 멈춤 현상 수정

**요청:** [3/3] PDF 저장 중에서 멈춰. mso16B3.tmp 파일이 생겼어

**원인:** Word가 숨겨진 대화상자(보안 경고 등)를 표시하며 입력 대기

**수정:**
- `word.DisplayAlerts = 0` 추가 (팝업 완전 억제)
- `word.Documents.Open(..., ReadOnly=True)` 로 변경
- `ExportAsFixedFormat` PDF 전용 메서드로 교체
- **5분 타임아웃** 스레드 추가 → 초과 시 `taskkill /f /im WINWORD.EXE`

## 15. NoneType 오류 수정

**요청:** 오류: 'NoneType' object is not iterable

**원인:** `GoogleTranslator.translate()`가 특정 텍스트에서 `None` 반환

**수정:**
- `_safe_translate()` — None 반환 시 원문 유지
- `isinstance(r, str)` 타입 체크 전 구간 추가
- `do_chunk()` — `try/except`로 청크 단위 격리 (한 청크 실패해도 계속 진행)
- `f.result()` — 개별 오류 무시, 전체 중단 없음

## 16. 폰트 통일 (한글 eastAsia 속성)

**요청:** 출력 파일의 글씨체를 통일해줘. 완전 제각각이야

**원인:**
- DOCX에서 한글은 `w:eastAsia` 속성으로 별도 지정해야 함
- 기존 코드는 `w:ascii`/`w:hAnsi`만 설정 → 한글이 Windows 임의 폰트로 렌더링

**수정 (`_set_run_font`):**
```xml
<!-- 수정 전 -->
<w:rFonts w:ascii="Arial" w:hAnsi="Arial"/>

<!-- 수정 후 -->
<w:rFonts w:ascii="바탕" w:hAnsi="바탕" w:eastAsia="바탕" w:cs="바탕"/>
```

## 20. 본문 bold 제거 + 크기 축소

**요청:** 일반 본문 글자가 굵어서 보기 힘들어. 굵기 효과가 적용이 안 돼있는 거라면 글자 크기를 조그만 줄여줘

**원인:** `pdf2docx`가 원본 PDF의 bold 속성을 run에 그대로 복사

**수정 (`apply_translations`):**
- 본문 run에 `first.bold = False` 강제 설정
- 본문 크기 1pt 축소 (최소 9pt 유지) — 바탕 폰트가 같은 크기에서 더 두꺼워 보임

## 21. 각주 위첨자 복원

**요청:** 각주 표시 살려줘 (7, 8 같은 숫자가 일반 텍스트로 나와)

**원인:** 번역 후 모든 텍스트를 run[0]에 병합하면서 원본 superscript run 소멸

**구현 (`_split_footnotes`, `_FOOTNOTE_RE`):**
- 정규식 `(?<=[^\s\d])(\d{1,3})(?!\d)` 으로 각주 마커 감지
  - 단어·구두점 바로 뒤에 공백 없이 붙은 1~3자리 숫자
  - `10%`, `2.5배`, `1846년` 등 일반 숫자는 미감지
- run을 분리해 숫자 부분에 `w:vertAlign w:val="superscript"` 적용

```
"사망했습니다.7 한편" →
  run① "사망했습니다."  (바탕, 일반)
  run② "7"             (바탕, 위첨자)  ← 각주 복원
  run③ " 한편"         (바탕, 일반)
```

## 23. 페이지 수 최적화 (3단계 조정)

**요청:** 626장으로 거의 두 배 됐어 / 400장 정도 되도록 폰트 크기를 아주 약간만 줄이는 건 안 돼나 / 지금도 521 페이지야. 좀 더 줄여

**원인 분석 (626장 발생):**

| 원인 | 영향 |
|---|---|
| 줄 간격 1.0 → 1.4배 | 줄마다 40% 더 차지 → 페이지 약 +35% |
| 본문 `space_after = 5pt` | 2000단락 × 5pt ≈ 14페이지 분량 추가 |
| 제목 전후 여백 16pt | 제목마다 공간 추가 |

영어→한국어는 글자 수가 줄지만, 강제 여백이 그 이상으로 페이지를 키움.

**3단계 조정 과정:**

| 단계 | 줄 간격 | 본문 여백 | 폰트 축소 | 결과 |
|---|---|---|---|---|
| ref_design 적용 | 1.4배 | 5pt | −1pt | **626장** |
| 중간값 조정 | 1.25배 | 2pt | −1pt | ~480장 |
| 폰트 추가 축소 | 1.25배 | 2pt | −1.5pt | **521장** |
| 최종 조정 | **1.15배** | **0pt** | **−2pt** | **~400장** |

**최종 적용값:**
```python
LINE_SPACING     = 1.15
BODY_SPACE_AFTER = 0
HEAD_SPACE_AFTER = 4
HEAD_SPACE_BEFORE= 3
# apply_translations 내:
new_size_pt = max(9, size_pt - 2)   # 본문 2pt 축소
```

## 최종 아키텍처

```
PDF 입력
  │
  ├─ [1/3] pdf2docx ─────────────── 그림·표·레이아웃 보존 DOCX 변환
  │         └─ fitz.open() 으로 페이지 수 파악 + 시간 기반 진행 애니메이션
  │
  ├─ [2/3] deep-translator (GoogleTranslator)
  │         ├─ 단락 수집 (본문·표·헤더/푸터)
  │         ├─ ◆◆◆ 구분자로 묶음 → 1회 API 호출 (고속)
  │         ├─ 6개 병렬 스레드
  │         ├─ 폰트: 바탕(본문) / 맑은 고딕(16pt 이상 제목) 자동 선택
  │         ├─ 본문 bold 제거 + 2pt 크기 축소 (최소 9pt)
  │         ├─ 각주 숫자 → 위첨자 run 분리
  │         └─ 줄 간격 1.15배 (페이지 수 최적화)
  │
  └─ [3/3] win32com (Word)
            ├─ DisplayAlerts=0, ReadOnly=True, AutomationSecurity=3
            ├─ ExportAsFixedFormat (PDF 전용 메서드)
            ├─ 5분 타임아웃 + WINWORD.EXE 강제 종료
            └─ LibreOffice → DOCX 순서로 폴백

출력: 번역된 PDF
```

---

## 출력 문서 스타일 규칙 (최종)

| 항목 | 값 |
|---|---|
| 본문 폰트 | 바탕 (세리프) |
| 제목 폰트 | 맑은 고딕 (16pt 이상에 자동 적용) |
| 본문 bold | 항상 해제 |
| 본문 크기 | 원본 −2pt (최소 9pt) |
| 줄 간격 | 1.15배 |
| 본문 단락 후 여백 | 0pt |
| 제목 전/후 여백 | 3pt / 4pt |
| 각주 번호 | 위첨자(superscript) 복원 |
